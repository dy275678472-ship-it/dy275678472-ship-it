# 09 · UI 页面与用户流程

技术栈：Vue 3 + Vue Router + Vite（沿用现网）。保留可复用页面，按 V2 定位重排。

## 一级导航

```text
首页 | 长篇小说 | 短故事 | 案例阅读 | 价格 | 创作台
```

SEO 后台、运营后台属于管理员功能，不进入普通用户主导航。

## 首页结构（按顺序）

1. 长篇小说主卖点（主标题「让 AI 陪你写完一部长篇小说」）
2. 长篇创作演示
3. 短故事快速入口
4. 平台真实生成案例（来自审核通过的案例）
5. 小说大脑能力展示（人物/伏笔/剧情一致性）
6. 一致性展示
7. 计费说明（点数）
8. 每日免费额度
9. 用户作品案例
10. FAQ 与合规说明

首页双入口按钮：`开始写长篇小说` / `快速生成短故事`。

> 注意：本轮已修复首页 banner 负边距重叠与无效 `rgba(var())`；V2 重排时沿用修正后的样式基线。

## 页面清单与职责

| 页面 | 职责 |
|---|---|
| 首页 | 定位、演示、案例、计费、转化 |
| 案例阅读区 | 列表 + `/ep/{id}` 详情 + 「用这个风格创作」按钮 |
| 免费试用 | 游客试生成一次短内容（不保存），引导注册 |
| 注册/登录 | 账号密码；注册成功自动登录（现网已如此） |
| 创作控制台 | 作品列表 + 新建 + 进入编辑 |
| 小说设置 | 题材/风格/目标字数/人物/背景/冲突 |
| 大纲编辑器 | 总纲/分卷/章纲，可编辑 |
| 人物设定 | 人物档案与关系 |
| 章节编辑器 | 生成/停止/重生/局部修改/续写；显示预计消耗与实际扣费 |
| 小说大脑视图 | 人物状态、设定、未回收伏笔、章节摘要 |
| 点数充值 | 选套餐 → 支付宝 → 到账 |
| 消费记录 | `credit_transactions` 流水 |
| 我的作品 | 本人作品（现网 `/api/story/list` 已可用） |
| 导出 | TXT/Markdown |
| 管理后台 | 用户/作品/任务/订单/额度/审核 |
| 内容审核 | 审核队列（人工通过/驳回） |

## 关键交互

- 每个生成按钮点击前调 `/api/credits/estimate` 显示「预计消耗 X 点」，余额不足引导充值。
- 生成中显示任务状态（轮询 `generation_jobs` 或 SSE），失败提示已返还点数。
- 顶栏常驻显示点数余额（free + paid）。
