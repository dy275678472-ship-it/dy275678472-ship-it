# 02 · PRD（产品需求文档）

每个需求写成可开发、可验收。以下为 P0 需求。

## 1. 账号系统

- 账号名 + 密码注册（3–64 位账号名，密码 ≥8 位）；可选邮箱。
- 密码使用 bcrypt（现网已用）或 Argon2id 存储，禁止裸 SHA-256。
- 登录返回 JWT（HS256，密钥来自 `JWT_SECRET`，≥32 字符），默认 60 分钟有效。
- 支持找回密码（V2.1 可用邮箱/短信，其一即可）。
- 验收：注册即得 30 点；重复账号名返回 409；错误密码返回 401；令牌过期返回 401「登录已失效」。

## 2. 免费额度

- 游客：可试生成一次短内容，不保存（按 IP + 设备指纹限流，nginx 限流兜底）。
- 登录用户：每日 5 点免费额度，本地时区每天 0 点刷新，**不累计**。
- 生成失败返还的是「本次任务实际冻结的点数」，不影响每日额度已消费部分的判定。
- 后台可手工调整某用户额度（记流水）。
- 并发：同一用户同一时刻仅允许 N（默认 2）个进行中的生成任务，超出返回 429。
- 验收：新用户当天可用额度 = 30（注册赠）在充值账户 + 5（每日）在免费账户；跨天后免费额度重置为 5 且不叠加。

## 3. 项目管理

- 新建长篇小说 / 短故事；保存草稿；作品归属当前用户。
- 「我的作品」只显示本人作品；按状态（草稿/已发布）筛选。
- 验收：A 用户无法读取/修改/删除 B 用户作品（返回 403/404）。

## 4. 小说设定

- 字段：题材、风格、目标字数、人物、背景、核心冲突。
- 短故事可省略分卷；长篇支持分卷。

## 5. 大纲生成

- 生成总纲、分卷大纲、章节大纲（起承转合）。
- 扣费：完整大纲 3 点；10 章章纲 5 点。

## 6. 章节生成

- 生成、停止、重新生成、局部修改、续写。
- 每章独立存储（`chapters` 表），支持版本（`chapter_versions`）。
- 扣费：约 2000 字/章 10 点；>2000 字按实际输出字数分档；重新生成 8–10 点。
- 生成前显示预计消耗；成功后按实际结算；失败全额返还。

## 7. 一致性（小说大脑）

- 每章生成后自动：抽取章节摘要、更新人物状态、检测设定冲突、登记/回收伏笔。
- 续写时按「最近若干章正文 + 全书摘要 + 人物状态 + 设定 + 未回收伏笔」组织上下文。
- 验收：连续生成 ≥20 章，人物姓名/关系/关键设定不发生无理由改变（人工抽检 + 冲突检测报告）。

## 8. 额度系统与按量付费

- 生成流程强制：预冻结 → 成功结算（实扣）→ 失败返还。
- 账户余额只是流水（`credit_transactions`）的计算结果，不允许直接改 `balance` 作为唯一账本。

## 9. 订单与支付（支付宝）

- 创建订单 → 拉起支付宝 → 异步回调验签 → 核对金额/商户号/交易号 → 幂等入账 → 点数到账。
- 任何未验签或金额不符的回调一律拒绝且不入账。
- 验收：伪造 `order_id + status=success` 无法使订单变为已支付；重复回调只入账一次。

## 10. 导出

- TXT、Markdown（V2.1 再加 DOCX）。

## 11. 内容安全

- 生成前后审核（敏感词 + 模型审核），违规提示与人工处理入口。
- 平台自动生成的案例必须过审核队列后才公开。

## 12. 公开案例与阅读前台

- 平台每日自动生成 3–10 篇；审核通过后发布到 `/ep/*` 阅读页。
- 阅读页放「用这个风格创作」的转化按钮。

## 13. 运营后台

- 用户、作品、任务、订单、额度、内容审核队列、案例发布计划。
- 仅管理员可见，不进入普通用户主导航。
