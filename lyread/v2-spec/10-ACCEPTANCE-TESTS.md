# 10 · 端到端验收标准

防止再次出现「页面有了、实际不能用」。所有用例必须在测试环境（支付宝沙箱）自动或半自动通过。

## 主链路（必须全绿）

```text
注册
→ 获得注册赠送 30 点 + 当日免费 5 点
→ 创建作品（归属当前用户）
→ 生成大纲（扣 3 点，余额正确）
→ 生成 10 章章纲（扣 5 点）
→ 生成第 1 章（预冻结 10 点 → 成功结算 → 实扣正确 → 章节入 chapters 表）
→ 记忆更新（人物状态/摘要/伏笔写入）
→ 生成第 2 章（上下文包含前章记忆，人物不丢失）
→ 充值（创建订单 → 支付宝沙箱 → 回调验签 → 点数到账）
→ 导出作品（TXT/MD 内容完整）
```

## 计费与额度用例

| 用例 | 期望 |
|---|---|
| 新用户注册 | credit_transactions 出现 signup_bonus(+30)；free_balance=5 |
| 生成成功 | reserve → settle，两条流水；balance_after 正确 |
| 生成失败 | reserve → refund，全额返还；job=failed |
| 余额不足 | 返回 402/「点数不足」，不创建 job，不扣费 |
| 每日额度 | 跨天后 free_balance 重置为 5，不累计 |
| 并发限制 | 同用户超过 N 个进行中任务返回 429 |

## 支付安全用例（必须全部拒绝）

| 攻击 | 期望 |
|---|---|
| 伪造 `order_id + status=success` 调回调 | 拒绝，验签失败，不入账 |
| 篡改金额的回调 | 拒绝（金额不符） |
| 重复回调同一 `trade_no` | 只入账一次（幂等） |
| 未支付订单查询 | 状态 created，点数未到账 |

## 权限与越权用例

| 用例 | 期望 |
|---|---|
| A 读 B 的作品/章节 | 403/404 |
| A 改/删 B 的作品 | 403 |
| 未登录调创作接口 | 401 |
| 令牌过期 | 401「登录已失效」 |
| 普通用户访问 `/api/admin/*` | 403 |

## 一致性（小说大脑）用例

- 连续生成 ≥20 章，人工抽检人物姓名/关系/关键设定无无理由变化。
- 一致性检测能报告已知植入的矛盾（测试用例里故意制造冲突）。

## 内容安全用例

- 命中敏感词的生成被拦截或标记待审。
- 平台自动生成的案例未过审核不出现在公开阅读区。

## 非功能

- 单章生成 P95 延迟、每章真实 token 成本记录可查。
- 服务重启后：进行中任务状态可恢复/可查询（不因内存丢失）。
- 备份：数据库每日备份可恢复。
