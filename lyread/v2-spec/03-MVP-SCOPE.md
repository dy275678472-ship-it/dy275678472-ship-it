# 03 · MVP 范围表

## 现有功能如何处理

| 功能 | V2 处理 | 现状（本轮已做） |
|---|---|---|
| 注册登录 | 重构（bcrypt + JWT + 找回密码） | 注册/登录已修复可用 |
| AI 生成书名 | 保留 | 已支持匿名试用 |
| AI 大纲 | 保留并升级 | 需登录 |
| 章节生成 | 重构（独立 chapters 表 + 计费） | 仍写 JSON，待重构 |
| 每日免费额度 | 新增 | 未做 |
| 点数充值 | 新增 | 未做 |
| 支付闭环（支付宝） | 新增（验签+幂等） | 未做（V1.9 回调无验签，风险） |
| 小说记忆（小说大脑） | 新增 | 未做 |
| 平台案例 | 重构（真实生成+审核） | `contents` 表有数据，无审核流 |
| 爆款预测 | 暂缓（真实数据版留 P1） | 调度器已真实运行 |
| SEO 后台 | 暂缓/保留只读 | 存在 |
| IP 市场 | 下线 | 前端有入口，后端无路由 |
| 全网分发 | 下线 | 同上 |

## P0（能安全收费前必须完成）

| 模块 | 必须实现 |
|---|---|
| 账号系统 | 注册、登录、找回密码、会话管理 |
| 免费试用 | 游客试生成一次；登录后每日领免费额度 |
| 项目管理 | 新建小说/短故事、保存草稿、作品归属 |
| 小说设定 | 题材、风格、目标字数、人物、背景、核心冲突 |
| 大纲生成 | 总纲、分卷、章节大纲 |
| 章节生成 | 生成、停止、重生、局部修改、续写 |
| 一致性 | 人物状态、剧情摘要、设定、伏笔持续维护 |
| 额度系统 | 免费额度、充值额度、冻结、扣除、返还 |
| 按量付费 | 按任务/章节扣费 |
| 订单支付 | 创建订单、真实回调、幂等、对账 |
| 导出 | TXT、Markdown |
| 内容安全 | 生成前后审核、违规提示、人工入口 |
| 公开案例 | 自动生成 + 审核后公开到阅读前台 |
| 运营后台 | 用户/作品/任务/订单/额度/审核 |

## P1（验证付费后再做）

短故事专用模板、长篇记忆增强、爆款评分真实数据版、章节质量评分、多模型路由、成本统计、邀请奖励、自动封面、用户公开发布。

## P2（有真实用户后再做）

IP 版权交易、全网分发、SEO 自进化、分布式强化学习、收益分成、自动内容变异、终身无限、复杂会员等级。

## 核心链路（做稳这条即可收费）

> 免费试写 → 创建故事 → 生成大纲 → 连续生成章节 → 人物剧情不丢失 → 按章付费 → 随时导出。
