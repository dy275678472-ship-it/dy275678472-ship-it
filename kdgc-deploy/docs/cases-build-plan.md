# 行业案例建设方案

> 对应线上页面：`/cases/`  
> 现有案例过简（无图、短文）；本方案用于正式建设案例库。

## 问题

- 无现场图/产品图，缺少量化结果与客户场景  
- www.kdgc.cc 亦无独立案例库，本站需新建而非继续占位  

## 每篇标准结构

1. 封面图（≥1200px）  
2. 客户与行业（可脱敏）  
3. 挑战（工况/量程/响应/体积）  
4. 方案（传感器型号 + 控制器 + 接口）  
5. 实施节点（打样→标定→小批→量产）  
6. 结果（≥2 个量化指标）  
7. 产品详情入口 + 咨询 CTA  

## 首批建议案例

| 案例 | 产品 | 需补充素材 |
|------|------|------------|
| 航空面罩供氧监测试制 | 面罩用氧传感器 | 试制照片、性能对比、时间节点 |
| 工业气体氧分压在线监测 | KD0100-02S-T1 | 安装图、工况、精度验收 |
| 紧凑型设备插针式集成 | KD0100-02S-TO | 尺寸、重量、接线定义 |
| 柴油机 SCR/OBD 配套（规划） | 氮氧/氧传感路线 | 客户许可、台架数据 |

## 生产流程

销售/项目提交《案例采集表》→ 技术审参 → 市场撰写 → 法务脱敏 → 上线。  
每月 ≥1 篇；季度复盘「案例页 → 咨询表单」转化。

## 近期交付

业务方提供 1 组真实项目素材后，按本模板 48 小时内上线首个完整案例页，并替换规划页为正式列表。
