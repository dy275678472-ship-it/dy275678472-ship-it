## 二、知识库优化建议（按优先级）

### P0 — 尽快让栏目「看起来有内容」

1. **用新闻拆文上线首批正式页**  
   - 将《一文读懂氧传感器》拆为：原理与 Nernst、氧化锆/氧化钛分类、故障与检测、行业应用。  
   - 将《氮氧传感器市场》改写为「SCR/OBD 应用」知识库长文（对应选题 #5 / #10）。  
   - 好处后，`/knowledge/` 从「规划页」改为「文章列表 + 规划入口」。

2. **导航诚实标注**  
   - 正式文未满 4 篇前，导航可用「知识库（建设中）」或在列表顶置 `plan-banner`，避免被当成空站。

3. **每篇固定转化模块**  
   - 文末：相关产品（探头 / 插针 / 面罩）+「咨询选型」按钮。  
   - 参数只引用产品详情页已公开数据，禁止编造。

### P1 — 内容与 SEO

4. **选题执行顺序**：先 #2+#4（选型+接线）服务询盘，再 #1+#3（原理+量程）做 SEO。  
5. **配图包**：接线定义、量程/精度曲线、探头 vs 插针对比图 — 先出图再写长文。  
6. **内链矩阵**：新闻 ↔ 知识库 ↔ 产品详情三角链接；同一关键词只保留一篇「权威页」。

### P2 — 中英文策略

7. **英文不做全量翻译**（成本高、询盘量暂低）：每篇给 200–300 词英文摘要 +「Read full Chinese article」。  
8. **若确需俄语站**：建议先做俄语产品规格 PDF / 一页式 landing，再考虑全站；当前产品线与俄语市场匹配度需业务确认，不宜与中英文同优先级。

## 三、产品案例优化建议（按优先级）

### P0 — 样板优先

1. **只做 1 个完整样板案例再扩量**  
   - 首选：航空面罩试制 **或** 工业氧分压在线监测（素材可控、与现有 SKU 直接对应）。  
   - 拒绝「四篇空壳同时上线」。

2. **硬门槛**  
   - 封面图 ≥1200px  
   - ≥2 个量化结果  
   - 客户授权或脱敏完成  
   - 链到对应产品详情  

### P1 — 流程与转化

3. **落地《案例采集表》字段**：行业、工况、型号、接口、节点时间、指标、照片、授权。  
4. **列表页信息架构**：行业标签 + 1 个结果数字 + 封面；详情页挑战/方案/结果三栏。  
5. **产品页反链**：SKU 详情增加「相关案例」（有内容再显示，避免空模块）。

### P2 — 中英文

6. 英文案例用 Challenge / Solution / Results 三段摘要即可。  
7. SCR/OBD 案例等客户许可与台架数据到位后再立项，避免虚构故事。
