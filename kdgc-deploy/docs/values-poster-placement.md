# 价值观海报投放说明

## 推荐位置

| 位置 | 用法 | 原因 |
|---|---|---|
| **关于页 `/about/#values`（主位）** | HTML 三卡 + 完整海报图 | 与企业文化/公司介绍同页，信息完整且不抢首页首屏 |
| **首页中段（轻量入口）** | 三卡文字入口，链到关于页 | 传递 5 年质保 / 创新 / 7×24，手机可读；不塞整张长图 |
| 联系页 | **不放整图** | 已有响应/服务承诺区，避免重复 |
| Hero / 首屏 | **不放** | 海报信息密度高，破坏首屏「品牌+一句主张+CTA」 |

## 手机端策略

- 三卡纵向堆叠，字号可点可读（非依赖海报内嵌小字）
- 海报单独展示，可点击看大图；窄屏不裁切关键文案区块
- 导航菜单点击后自动收起，按钮热区 ≥44px
