# 知识库建设规划

> 对应线上页面：`/knowledge/`  
> 内容对齐官网 www.kdgc.cc 真实产品线（变频氧传感器 / 氮氧传感器），不使用陶瓷基板占位文案。

## 目标

建立可检索、可转化线索的技术内容资产，服务工程师选型与采购决策，并与产品详情、新闻互相内链。

## 栏目结构

1. **原理基础**：氧化锆/氧化钛、Nernst 原理、空燃比、变频氧传感差异  
2. **产品选型**：探头 vs 插针、面罩低温型、KD0100-03 配套、电气连接  
3. **应用场景**：车用 SCR/OBD、航空面罩、工业燃烧气氛、特种气体  
4. **安装与维护**：加热电压、温度/气流边界、失效模式、质保注意点
