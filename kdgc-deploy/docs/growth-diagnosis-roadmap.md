### 最大的 10 个问题

1. **品牌资产不稳定**：线上 Logo 曾被「航宇救生」覆盖 → 手机端品牌灾难  
2. **无结构化数据 / 弱技术 SEO**：无 JSON-LD，Core Web Vitals 未监测  
3. **关键词覆盖窄**：缺「选型对比 / 参数查询 / 竞品替代 / 采购招标」类高意图页  
4. **案例脱敏后信任不足**：无授权数据、无可下载规格书 PDF  
5. **CMS 与静态站双轨**：后台改库 ≠ 前台更新，运营无法独立迭代  
6. **转化漏斗无测量**：无清晰的事件追踪（咨询点击、表单、电话）  
7. **内容更新慢**：新闻偏团建，技术内容未形成周更节奏  
8. **孤岛页与次级栏目**：技术能力/应用场景信息薄，SEO 贡献弱  
9. **社媒与私域空白**：B2B 采购决策链未触达  
10. **外链与权威几乎为 0**：E-E-A-T 靠自说自话

### 最大的 10 个增长机会

1. **「变频氧传感器」品类词 + 型号词矩阵**（低竞争蓝海相对汽车大厂）  
2. **选型工具页**（T1 vs TO vs 面罩）→ 高转化入口  
3. **可下载规格书 / 接线说明书 PDF** → 线索质量↑  
4. **知识库扩到 30–50 篇** 做内容集群吃长尾  
5. **匿名案例 + 指标区间**（在合规前提下）提升询盘率  
6. **百度/搜狗工业词广告** 承接高意图（中预算即可见效）  
7. **知乎 + 视频号 + 微信** 做工程师信任内容  
8. **邮件/企业微信跟进 SOP** 降低单线索成本  
9. **英文站补强** 接外贸/集成商询盘  
10. **产学研背书页面**（中科大转化、专利、ISO）做信任中枢

## 4. UX 与转化优化

### 路径与流失点
```
首页 → 产品 → 知识/案例 → 联系
流失：产品页无「下一步」；案例缺证据；联系页地图偶发失败；无规格书门控线索
```

### 转化提升方案（按优先级）

| 优先级 | 动作 | 预期 |
|---|---|---|
| P0 | 全站统一双 CTA：`要规格书` / `工程师咨询` | 询盘+20–40% |
| P0 | 产品页增加「3 步选型」锚点链到选型页 | 降低选择瘫痪 |
| P0 | 表单字段：姓名/公司/场景/型号兴趣/手机；成功页引导加企业微信 | 线索质量↑ |
| P1 | PDF 下载需留资（可开关） | 高意向线索 |
| P1 | 信任条：专利/ISO/质保 在产品页复用 | 跳出↓ |
| P1 | 电话一键拨号热区加大（移动） | 移动转化↑ |
| P2 | 在线试样申请流程 | 销售可跟进 |
| P2 | 英文询盘表单独统计 | 外贸漏斗 |

**无公开定价页**（B2B 合理）：用「获取报价」代替价格表，避免电商比价伤害。
