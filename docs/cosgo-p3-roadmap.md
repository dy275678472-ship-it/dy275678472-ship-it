## P3 能做什么？

P3 的核心是从「SEO 基建 + 内容填充」转向 **流量变现、用户留存、数据驱动增长**。

### P3-A：转化与留存（最大杠杆）

| 项目 | 说明 | 预期影响 |
|------|------|----------|
| **活动提醒邮件** | 订阅用户按城市推送 7 天内漫展 | 复访率 +30% |
| **收藏漫展需登录** | 注册动机：收藏活动、订阅提醒 | 注册转化 +15% |
| **攻略 PDF 下载** | 「出发前清单」换邮箱（已有 subscribe 基础） | 订阅转化 +20% |
| **Stripe 打赏优化** | 活动详情/攻略文末引导「支持独立开发」 | 月收入 ¥500+ |
| **Klook 联盟深化** | 城市页 + 活动页 + 国际城市页统一 Widget | CPS 收入 |

### P3-B：内容与 SEO 深化

| 项目 | 说明 | 目标 |
|------|------|------|
| **攻略扩至 40+ 篇** | 现有 cron 每日生成 + 自动发布 | sitemap 博客 URL × 40 |
| **城市 × 攻略内链矩阵** | 成都/上海等城市场景文链到 `/city/{slug}` | 本地长尾排名 |
| **国际城市内容** | 东京/首尔页补充 JA/KO 正文（已有 hreflang） | 海外 Cos 出行流量 |
| **年度漫展报告** | 「2026 全国漫展数据」信息图 + 长文 | 品牌 PR + 外链 |
| **视频嵌入** | B站场照教程 embed 到攻略页 | 停留时长 +40% |

### P3-C：供给侧与社区

| 项目 | 说明 | 现状 |
|------|------|------|
| **摄影师认领优化** | 简化认领流程、展示已认领标识 | DB 273 位，多数未认领 |
| **用户评价展示** | 首页/摄影师页展示真实返图评价 | 目前无 UGC |
| **城市微信群导流** | 按城市分群（成都 Cos、上海 Cos） | 冷启动方案已有 |
| **漫展主办方 BD** | 互换 Banner、官方活动合作 | 需人工 BD |

### P3-D：基础设施（与 zhenxi 共享）

| 项目 | 说明 | 前置条件 |
|------|------|----------|
| **Cloudflare CDN** | 橙云代理，TTFB -30% | DNS 权限 |
| **服务器升配 8G** | Swap 从 2G 降至 <500MB | 腾讯云审批 |
| **Hermes 迁出** | 释放 3.1G 磁盘 + 500MB swap | 迁移决策 |
| **GSC + Umami 周报** | 每周自动邮件摘要 | SMTP 已有 |
| **Uptime 监控告警** | 磁盘 >80%、服务 down | 可选 Uptime Kuma |

### P3-E：社交矩阵（运营向，非纯代码）

| 渠道 | 30 天动作 | 引流目标 |
|------|-----------|----------|
| 小红书 | 「2026 漫展日历」信息图 × 6 | `/activities` |
| B站 | 「第一次漫展 Cos 准备」5 分钟 | `/blog` |
| 微博 | CP/漫展关键词实时蹭热点 | 活动详情页 |
| 公众号 | 月度攻略合集 + 邮件订阅 | `/api/subscribe` |

## P3 优先级排序

```
P3-1  Cloudflare CDN           ← 性能/成本比最高，需 DNS
P3-2  活动提醒邮件              ← 留存杠杆（基于 Subscriber 表）
P3-3  攻略扩至 40 篇 + 城市内链  ← SEO 复利
P3-4  Klook 联盟全站覆盖        ← 变现
P3-5  摄影师认领流程优化         ← 供给侧转化
P3-6  收藏/登录激励             ← 注册转化
P3-7  社交内容矩阵（运营）       ← 需人工
P3-8  年度漫展报告 IP           ← 品牌
```
